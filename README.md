# 📱 Modern RGB LED Kumandası (Android)

Android cihazların dahili **IR Blaster (Kızılötesi)** donanımını kullanarak standart 24 tuşlu RGB şerit LED alıcılarını kontrol eden açık kaynaklı, modern bir kumanda uygulamasıdır.

---

### ✨ Özellikler
* **Modern Stüdyo Arayüzü:** Koyu tema ve kartlı modern tasarım.
* **Hissedilebilir Geri Bildirim:** Tuşlara basıldığında fiziksel kumanda hissi veren mekanik yaylanma animasyonu ve titreşim (haptic feedback).
* **Standart 24 Tuş Desteği:** 16 farklı renk tonu, açma/kapatma, parlaklık (DIM) ve 4 dinamik sahne modu (Flash, Strobe, Fade, Smooth).
* **38 kHz NEC Protokolü:** Piyasadaki standart RGB 5050 / 3528 alıcılarla tam uyumlu sinyal yapısı.
